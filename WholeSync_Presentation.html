Robustness & Hardening

Security: We Don't Compromise

Hardened against OWASP Top 10 vulnerabilities directly at the framework and database layers.

OWASP A01: Broken Access Control

Dual-Role RBAC Enforcement

Wholesaler operations (Excel ingestion, catalog edits, item removals) are strictly gated with @wholesaler_required view decorators. Retailers cannot alter supplier records.

OWASP A03: Injection

100% Parameterized ORM Queries

Zero raw SQL query string concatenation. All database operations use compiled Django ORM querysets with parameter binding, mathematically neutralizing SQL injection.

OWASP A07: Auth Failures

PBKDF2-SHA256 & IP Rate Limiting

Passwords are salted and hashed using PBKDF2 with 720,000 iterations. Auth endpoints are protected by django-ratelimit to halt dictionary brute-force attacks.

OWASP A02: Cryptographic Failures

HMAC Verification Tokens

Account activation uses SHA-256 HMAC cryptographic tokens tied to a 24-hour expiration window. Forged, reused, or expired tokens are immediately discarded.

Viva Defense

Faculty Q&A: Ready-Made Technical Answers

How we defend our architectural choices against common examiner trap questions.

Q1: "Why didn't you build this with the MERN stack (React / Node.js)?"

Answer: Django provides built-in ORM security against SQL injection, CSRF protection, secure session management, and administrative dashboards out-of-the-box. In Node.js/React, developers rely on dozens of third-party npm packages, creating supply-chain security vulnerabilities and 500MB runtime footprints unsuited for low-cost cloud deployment.

Q2: "What happens if your Redis or Celery worker crashes in production?"

Answer: WholeSync implements automatic graceful degradation! When the Celery dispatcher detects a socket connection failure, it catches the error and immediately dispatches the verification email synchronously. Zero emails are ever dropped.

Q3: "How do you prevent malicious wholesalers from uploading corrupt Excel files?"

Answer: The upload endpoint validates the file MIME type, extracts required header schemas, validates cell datatypes line-by-line, and executes the database insert inside an atomic transaction (transaction.atomic()). If any row fails, the entire batch rolls back cleanly.
